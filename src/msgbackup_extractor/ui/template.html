Auswahl herunterladen

Für eine einzelne Datei geht es kürzer: in der Einzelansicht Rechtsklick auf das Bild und „Bild speichern unter…". Das ist eine Funktion des Browsers und geht an der Sperre vorbei.

--output
Das Exportverzeichnis, aus dem gesammelt wird — dort liegt das Export-Manifest. Steht schon richtig drin, nichts zu tun.
--target
Wohin die Auswahl kopiert wird. Das darfst du ändern, wenn du sie woanders haben willst. Die CLI legt das Verzeichnis an; es muss außerhalb des Exports liegen.

Zum Speichern: Rechtsklick auf das Bild → „Bild speichern unter…". Ein Download-Knopf ist hier nicht möglich — aus einer lokal geöffneten Seite lädt der Browser nichts herunter.

← → blättern, Leer auswählen, Esc schließen
