02

Ist deins dabei?

Threema

Alles, was im Backup liegt, kommt raus — auch die Medien, die Threema in seiner eigenen Datenbank hält, wo ein Werkzeug auf Dateiebene überhaupt nichts findet.

WhatsApp

Alles, was im Backup liegt, kommt raus. Bei manchen Einträgen wurde nur WhatsApps eigenes kleines Vorschaubild überhaupt gespeichert — die sind entsprechend gekennzeichnet, statt als Original durchzugehen.

Signal — nein

Daran kann dieses Werkzeug nichts ändern: Signal hält seine Daten vollständig aus dem iOS-Backup heraus. Erkannt wird es, und dann wird dir genau das gesagt. Der Weg führt über Signals eigene Geräteübertragung.

03

Was du brauchst

Einen Mac oder PC

Auf macOS entwickelt und geprüft. Windows ist implementiert, aber nie an einem echten Backup gelaufen — das steht so in der Anleitung und wird nicht schöngeredet.

Ein lokales Backup

Mit dem Finder erstellt, unter Windows mit der Apple-Geräte-App oder iTunes — und auf deinem Rechner. Verschlüsselte Backups sind der Regelfall, damit kommt es zurecht; das Passwort wird nur eingetippt, nie als Argument übergeben.

Ein Terminal — einmal

Drei Terminal-Befehle für die Profis — oder einmal die App bauen und danach nur noch doppelklicken. Python 3.12 braucht es in beiden Fällen. Ganz offen: um diese eine Installation kommt niemand herum, und wenn dir schon die zu viel ist, ist das hier nichts für dich.

Etwas Plattenplatz

Etwa so viel, wie die Daten des Messengers selbst belegen. Das Backup wird nie kopiert, und die Chat-Ordner sind gratis — sie zeigen auf dieselben Dateien.

04

Wie du anfängst

Für alle — drei Schritte

1

Einmal installieren

Drei Zeilen im Terminal. Das einzige Mal, dass du etwas tippen musst.

git clone https://github.com/abnun/msgbackup-extractor.git python3 -m venv ~/.venvs/msgx ~/.venvs/msgx/bin/pip install -e .
2

Die App bauen

Ein Befehl, und es entsteht msgbackup-extractor.app in deinen Programmen — unter Windows eine .cmd auf dem Desktop.

scripts/build-app.py
3

Doppelklicken

Die App öffnet ein Terminal und fragt der Reihe nach: welches Backup, welcher Messenger, wohin. Sie zeigt bei jedem Schritt den Befehl, den sie ausführt — wer sie zweimal benutzt hat, kann sie weglassen. Am Ende öffnet sich die Ansicht zum Durchsehen.

Zwei Fallen

Das Terminal braucht Festplattenvollzugriff, und es muss danach neu gestartet werden — sonst kann es das Backup gar nicht lesen.

Lege die virtuelle Umgebung nicht in iCloud Drive. iCloud versteckt die .pth-Dateien, Python überspringt sie dann stillschweigend, und die Installation sieht gelungen aus, ist es aber nicht. Das Handbuch zeigt, wie man das prüft.

Warum die App ein Terminal öffnet und keine stille Oberfläche ist: ein verschlüsseltes Backup braucht ein Passwort, und das wird ausschließlich eingetippt, nie weitergegeben.

Vollständige Anleitung

Für Fortgeschrittene — die einzelnen Befehle

Genau das, was die App für dich ausführt. Wer die Kommandozeile kennt, braucht die App nicht.

1

Erst schauen, nicht anfassen

Zeigt, welche Messenger im Backup stecken und was darin liegt. Schreibt überhaupt nichts.

msgx analyze --backup ~/…/Backup/<Gerät>
2

Erst proben, dann ernst machen

Mit --dry-run zeigt es, was passieren würde, und schreibt nichts. Denselben Plan führt der echte Lauf aus, die Probe kann sich also nicht anders verhalten als der Ernstfall.

msgx extract --backup … --output ~/export/threema
3

Durchsehen

Erzeugt die Seite. Du öffnest sie per Doppelklick, wählst dort aus und kopierst entweder direkt im Browser oder mit msgx collect.

msgx ui --output ~/export
05

Warum du es nachprüfen kannst

Kurz gesagt: weil du mir nichts davon glauben musst. Zu jedem dieser Punkte gibt es im Quellcode einen Test, der fehlschlägt, wenn er nicht mehr stimmt, und du kannst sie selbst ausführen: python -m pytest.

Das Backup wird nur gelesen

Vor und nach jedem vollen Durchlauf wird ein Fingerabdruck jeder Datei gebildet und verglichen. Gegentests belegen, dass der Fingerabdruck eine Änderung bemerken würde.

Es verlässt nichts den Rechner

Kein Teil des Quellcodes importiert ein Netzwerkmodul. Statisch geprüft, und nochmals mit vollständig abgeschaltetem Netzzugriff.

Es kommt nichts kaputt an

Der SHA-256 jeder geschriebenen Datei wird zurückgelesen und mit dem der Quelle verglichen. Nur der Vergleich zählt, nie die Behauptung.

Eine Bedingung

Das ist für dein eigenes Backup. Darin stehen Nachrichten, die andere Leute dir geschickt haben, und private Nutzung ist eine Sache, das Weitergeben eine andere. Es auf das Backup einer anderen Person anzuwenden, kann eine Straftat sein. Lass es.
