Die Software „msgbackup-extractor"

Die Software läuft vollständig auf Ihrem Rechner. Sie liest ein lokales Apple-iPhone-Backup und schreibt die daraus gewonnenen Dateien in ein von Ihnen bestimmtes Verzeichnis. Es gibt kein Benutzerkonto, keine Registrierung und keine Übertragung an mich oder an Dritte.

Sie enthält keinen Netzwerkcode. Anders als bei vielen lokalen Programmen gibt es auch keine Aktualisierungsprüfung, die im Hintergrund etwas abruft. Das ist nicht bloß eine Zusage: kein Modul der Software importiert ein Netzwerkmodul, und beide Eigenschaften werden bei jedem Testdurchlauf geprüft — statisch über die Importe und zusätzlich dynamisch mit abgeschaltetem Netzwerkzugriff. Nach neuen Versionen sehen Sie selbst im Quellcode-Verzeichnis.

Das Apple-Backup wird ausschließlich gelesen und nie verändert. Die Ausgabe geht nur in das von Ihnen angegebene Verzeichnis. Ein Verzeichnis, das in einen Cloud-Dienst synchronisiert, wird zurückgewiesen, damit das Betriebssystem die extrahierten Nachrichten nicht hochlädt.

Die Berichte und Protokolle der Software sind bewusst so aufgebaut, dass sie keine Nachrichteninhalte enthalten und Dateipfade standardmäßig maskiert sind, damit Sie sie bei einem Problem gefahrlos weitergeben können. Ob Sie das tun, entscheiden Sie; die Software versendet nichts von sich aus. Das Passwort eines verschlüsselten Backups wird nur interaktiv abgefragt und erscheint weder in Protokollen noch in Kommandozeilenargumenten.
